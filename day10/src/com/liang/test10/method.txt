一、Collection 公共方法（List、Set 都拥有）
(1)
boolean add(E e)                // 添加元素
boolean remove(Object o)        // 删除指定元素
boolean contains(Object o)     // 判断是否包含元素
int size()                      // 获取元素个数
boolean isEmpty()               // 是否为空
void clear()                    // 清空所有元素
Iterator<E> iterator()          // 获取迭代器
Object[] toArray()              // 转数组
boolean addAll(Collection<? extends E> c) // 批量添加
boolean removeAll(Collection<?> c)        // 删除交集
boolean retainAll(Collection<?> c)        // 保留交集
二、List 特有方法（有序、可重复、支持下标）
(1)
void add(int index, E element)       // 指定下标插入
E get(int index)                     // 根据下标获取元素
E set(int index, E element)          // 修改下标位置元素，返回旧值
E remove(int index)                  // 根据下标删除，返回被删元素
int indexOf(Object o)                // 正向查找，返回首次出现下标，找不到-1
int lastIndexOf(Object o)            // 反向查找，返回最后出现下标
List<E> subList(int from, int to)    // 截取子集合（左闭右开）

(2)
LinkedList 额外常用（双链表）

void addFirst(E e)
void addLast(E e)
E getFirst()
E getLast()
E removeFirst()
E removeLast()
三、Set 接口
(1)
✅ 没有下标相关方法！ 没有 get (index)、indexOf ()
只有 Collection 基础方法：

boolean add(E e);
boolean remove(Object o);
boolean contains(Object o);
int size();
void clear();
boolean isEmpty();
HashSet / LinkedHashSet / TreeSet
(2)
TreeSet 额外独有：

E first()        // 获取最小元素
E last()         // 获取最大元素
E lower(E e)     // 小于e的最大元素
E higher(E e)    // 大于e的最小元素
四、Map<K,V> 键值对集合（独立接口）
(1)
没有继承 Collection！

V put(K key, V value)               // 存放键值；key重复会覆盖旧value，返回旧value
V get(Object key)                   // 根据key获取value，无key返回null
V remove(Object key)                // 根据key删除，返回被删除的value
boolean containsKey(Object key)     // 是否包含指定键
boolean containsValue(Object value) // 是否包含指定值
int size()
void clear()
boolean isEmpty()

// 获取视图（非常常用）
Set<K> keySet()                     // 获取所有key集合
Collection<V> values()              // 获取所有value集合
Set<Map.Entry<K,V>> entrySet()      // 获取所有键值对（遍历首选）
(2)
Map.Entry（entrySet 里面的键值对对象）

K getKey();
V getValue();
V setValue(V value);
(3)
Java8 新增高频实用方法（开发超级常用）

V getOrDefault(K key, V defaultValue) // 取不到key返回默认值
void forEach(BiConsumer action)
V putIfAbsent(K key, V value)         // key不存在才存入
V computeIfAbsent(K key, Function)    // key不存在，执行逻辑生成value存入
V computeIfPresent(K key, BiFunction) // key存在才更新
